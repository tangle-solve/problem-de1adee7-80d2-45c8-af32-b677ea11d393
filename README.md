### ALGO-000195: Efficient uniform-distribution DNF learning from examples alone
- **Subfield:** Learning complexity and cryptographic foundations
- **Open:** Learn polynomial-size DNF under the uniform distribution in time polynomial in dimension, DNF size, and inverse error, using random labeled examples but no membership queries.
- **Status:** Quasipolynomial Fourier-based learning is known. Jackson’s polynomial-time Harmonic Sieve uses membership queries and therefore does not solve this version.
- **Type:** theory
- **Why:** Separates passive data access from active query access for a basic expressive concept class.
- **Key works:** Linial, Mansour, and Nisan (1993), *Constant Depth Circuits, Fourier Transform, and Learnability*; Jackson (1997), *An Efficient Membership-Query Algorithm for Learning DNF with Respect to the Uniform Distribution*.
